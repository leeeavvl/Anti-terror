Добавить источник

Заполните форму, чтобы начать наблюдение за конкретным публичным пабликом, каналом или аккаунтом. Приложение не будет читать личные сообщения и не совершает никаких действий на платформе — только собирает публичные посты и показывает сигнал специалисту.

Нужен токен доступа ВКонтакте с правом чтения стены (например, токен пользователя/сообщества или сервисный токен из vk.com/dev). Сам токен сюда не вводится — только имя переменной окружения, в которой он задан (см. .env). Приложение читает только публичную стену паблика (метод wall.get) и никогда не пишет на платформу.

Нужен бот, созданный через @BotFather, добавленный администратором в целевой публичный канал, группу или супергруппу (иначе Telegram не отдаёт боту сообщения). Для канала с комментариями бота нужно добавить администратором ещё и в его группу обсуждений отдельно — тогда приложение будет читать и комментарии под постами тоже, не только сами посты. Видно будет только то, что появится после добавления бота — старую историю Bot API не показывает. Сам токен бота сюда не вводится — только имя переменной окружения, в которой он задан (см. .env). Приложение только читает новые сообщения и никогда не отправляет их от имени бота.

Работает как обычный браузер: скачивает публичную страницу по указанной ссылке и следит за изменением её текста — токен или конфиг не нужны, укажите точную ссылку на страницу выше. Ограничение: сайты, которым для показа текста нужны JavaScript или вход в аккаунт (например Яндекс.Дзен — там даже на публичную статью сайт отвечает редиректом на форму входа), этим способом прочитать нельзя.

Технические параметры подключения к реальному API произвольной платформы. Токен доступа здесь не указывается — только имя переменной окружения, где он хранится.
